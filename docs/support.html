开始使用

1. 打开音乐网页

访问网易云音乐或 QQ 音乐网页版，正常选择歌单并开始播放。

2. 选择设置

点击扩展图标，可开关 AI 介绍、专辑资料，并选择主持音色。

3. 等待口播

切换到新歌时，原播放器进度条会显示准备状态，口播完成后歌曲继续播放。

常见问题

安装后没有播报怎么办？

先确认“播放前语音播报”已开启，然后刷新网易云音乐或 QQ 音乐页面。如果仍未生效，请在 chrome://extensions/ 确认扩展已启用，并重试切换歌曲。

为什么只听到简单播报或系统音色？

共享 AI 或语音服务可能暂时不可用、达到当日额度或请求超时。扩展会自动降级，避免阻塞音乐播放；稍后再试即可。

为什么同一张专辑不会重复介绍？

为避免打断听歌，同一播放会话中，一张专辑通常只在第一次出现时介绍。

需要提供自己的 API Key 吗？

不需要。供应商 Key 只配置在电台情歌服务端，不会发给浏览器扩展。

如何删除本地数据？

卸载扩展即可由浏览器清除本地设置与匿名安装标识。服务端数据请求请阅读隐私政策第 7 节。
