PRIVACY POLICY

隐私政策

这份政策说明电台情歌处理哪些数据、为什么需要它们，以及你可以如何联系我们。

生效及最后更新日期：2026 年 8 月 7 日

1. 适用范围与单一用途

本政策适用于“电台情歌”Chrome 浏览器扩展及其配套服务。扩展的单一用途是：在网易云音乐和 QQ 音乐网页版播放歌曲前，根据当前歌曲和专辑信息生成并播报电台式中文串场。

服务由 GitHub 用户 jackyrwj 维护。使用问题或隐私请求可通过帮助与支持页面提交。

2. 我们处理的数据

数据 用途 保存方式与期限
当前歌曲、歌手、专辑、平台、发行信息、歌曲或专辑 ID（页面可读取时）以及曲目位置 生成歌曲口播、专辑介绍、开场与收尾文案 通过 HTTPS 发送；生成文案缓存通常为 7 天，专辑相关缓存最长 30 天
随机匿名安装标识 限制共享服务调用频率，防止滥用 在浏览器本地生成和保存；服务端只用于限流计数，最长约 26 小时
IP 地址及其加盐哈希 网络传输、安全防护和频率限制 服务端使用加盐哈希进行限流，通常约 65 分钟；原始 IP 可能按 Vercel 的基础设施日志政策处理
功能开关、选择的音色 记住你的本地偏好并执行所选功能 仅保存在浏览器本地，卸载扩展后由浏览器清除

扩展不会读取或收集网易云音乐、QQ 音乐账号和密码、Cookie、支付信息、通讯录、精确位置，也不会收集完整播放历史或完整歌单。

3. 数据如何使用

  • 生成并返回用户正在收听内容对应的中文文案与语音。
  • 执行必要的限流、缓存、安全防护和故障排查。
  • 维持服务稳定并控制共享服务成本。

Chrome Web Store Limited Use：从 Chrome API 获得的数据仅用于提供电台情歌明确说明的单一用途。我们不会出售或转移这些数据用于个性化广告、信用评估或其他无关目的，也不会允许人工读取，除非为安全调查、遵守法律、处理滥用，或在你明确请求支持并同意时确有必要。

4. 服务提供商

为了提供核心功能，必要数据会由以下服务提供商代为处理：

  • Vercel：托管 API、处理网络请求并提供基础设施日志与安全能力。
  • 阿里云百炼 / DashScope：根据歌曲和专辑元数据生成文案与语音。
  • Upstash Redis：保存限流计数与生成结果缓存。

这些服务可能在你所在国家或地区之外处理数据，并分别受其隐私条款约束。我们只向其发送实现对应功能所需的数据。

5. 分享、出售与广告

我们不会出售用户数据，不投放个性化广告，也不会将数据用于与电台式口播无关的画像、营销、借贷或信用评估。除上述必要服务提供商外，只有在法律要求、保护服务与用户安全，或获得你明确同意的情况下才可能披露相关信息。

6. 安全与保留

扩展通过 HTTPS 与服务端通信；供应商 API Key 只保存在服务端环境变量中，不会发送给扩展。输入字段有长度和类型限制，服务端还使用限流与缓存减少不必要的处理。

到期的缓存和限流记录会自动删除。基础设施提供商可能根据其安全、备份和日志政策保留必要记录；我们会尽可能将数据限制在提供功能所需的最短期限内。

7. 你的选择与权利

  • 可以随时在扩展弹窗中关闭语音播报、AI 介绍或专辑资料播报。
  • 可以卸载扩展，浏览器会清除扩展的本地存储。
  • 可以联系我们查询、删除或限制与匿名安装标识有关的服务端数据。由于该标识不关联账户，请在仍安装扩展的设备上按支持说明提供该标识，以便我们定位。

生成结果缓存以歌曲或专辑元数据的哈希为键，通常不与身份直接关联。收到合理请求后，我们会在可识别和法律允许的范围内处理。

8. 儿童隐私

电台情歌不面向法律规定的低龄儿童，也不会故意收集儿童的个人信息。如果你认为儿童向本服务提供了个人信息，请联系我们处理。

9. 政策更新与联系

功能或数据实践发生实质变化时，我们会更新本页面和顶部日期；需要新的权限或新的数据用途时，会在生效前提供相应说明。

隐私问题、权利请求或安全问题，请通过 GitHub 隐私请求联系我们。请不要在公开 Issue 中粘贴账号、Cookie、API Key 或其他敏感信息。
